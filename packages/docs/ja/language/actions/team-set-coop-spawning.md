# team_set_coop_spawning


<AvailabilityCard reach="yes" />

## 説明

チームの協力スポーンを有効または無効にします。有効にすると、チームメイトや、そのように設定されたオブジェクトの位置でスポーンできるようになります。

<ActionParameters />

## 例

```megalo
action team_set_coop_spawning current_team true
```

HREK の `3nvasion.txt` より。
