# navpoint_set_visible_range


<AvailabilityCard reach="yes" />

## Description

Sets the distance at which a navpoint becomes visible.

<ActionParameters />

## Example

```megalo
action navpoint_set_visible_range current_object 0 20
```

Example from HREK `rocket_race.txt`.

## Notes

- Unlike other actions in Megalo, distance values for this action are equivalant to a whole world unit (as opposed to 0.1 world units.)
