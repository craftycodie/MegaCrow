# player_set_objective_allegiance_icon


<AvailabilityCard reach="partial" />

## Description

Sets the objective allegiance icon for a player. The icon is a constant integer (literal or number constant such as `k_engine_icon_elite`), in range `0`–`127`, or `-1` for none.

<ActionParameters />

## Example

```megalo
action player_set_objective_allegiance_icon current_player k_engine_icon_elite
```

Example from HREK `3nvasion.txt`.
