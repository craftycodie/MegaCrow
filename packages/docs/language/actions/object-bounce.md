# object_bounce


<AvailabilityCard reach="yes" />

## Description

Applies an upward impulse to an object. The impulse isn't directly upward and the horizontal part of the impulse is random.

<ActionParameters />

## Example

```megalo
action object_bounce new_skull
```
Example from HREK `headhunter.txt`.
