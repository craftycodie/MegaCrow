# player_set_objective_allegiance_icon


<AvailabilityCard reach="partial" />

## 説明

プレイヤーのオブジェクティブ所属アイコンを設定します。アイコンは定数整数（リテラル、または `k_engine_icon_elite` のような数値定数）で、範囲は `0`–`127`、なしの場合は `-1` です。

<ActionParameters />

## 例

```megalo
action player_set_objective_allegiance_icon current_player k_engine_icon_elite
```

HREK の `3nvasion.txt` より。
