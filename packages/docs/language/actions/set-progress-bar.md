# set_progress_bar


<AvailabilityCard reach="yes" />

## Description

Configures an object's progress bar display that will display to players when they are inside the object's boundary.

<ActionParameters />

## Example

```megalo
action set_progress_bar this_territory enemies offense_timer
```

Example from HREK `3nvasion.txt`.
