# object_bounce


<AvailabilityCard reach="yes" />

## 説明

オブジェクトに上向きのインパルスを与えます。インパルスは真上ではなく、水平成分はランダムです。

<ActionParameters />

## 例

```megalo
action object_bounce new_skull
```
HREK の `headhunter.txt` より。
