# object_get_orientation


<AvailabilityCard reach="yes" />

## 説明

オブジェクトの向きを出力変数に読み取ります。

- 1 は、オブジェクトが正立していることを意味します。
- 2 は、オブジェクトの右側面が上向きであることを意味します。
- 3 は、オブジェクトの背面が上向きであることを意味します。
- 4 は、オブジェクトの前面が上向きであることを意味します。
- 5 は、オブジェクトの左側面が上向きであることを意味します。
- 6 は、オブジェクトの底面が上向きであることを意味します。

<ActionParameters />

## 例

```megalo
action object_get_orientation current_object orientation
```

HREK の `rocket_race.txt` より。
