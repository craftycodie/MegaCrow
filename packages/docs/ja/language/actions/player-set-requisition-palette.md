# player_set_requisition_palette


<AvailabilityCard reach="yes" />

## 説明

プレイヤーにリクジションパレットを割り当てます。

<DocsBlock type="note" title="リクジションシステム">

`player_set_requisition_palette` は、Halo: Reach のリリース前に破棄されたリクジションシステムの一部です。リクジション機能の多くは現在もゲーム内に残っていますが、リクジションメニュー自体は消滅しているため、このアクションは初期のプリリリースビルド以外では実質的に意味がありません。

</DocsBlock>

<ActionParameters />

## 例

```megalo
action player_set_requisition_palette current_player req_sniper
```

HREK の `broken/tankinabox.txt` より。
