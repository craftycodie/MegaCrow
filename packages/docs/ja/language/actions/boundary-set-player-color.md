# boundary_set_player_color


<AvailabilityCard reach="partial" />

## 説明

オブジェクトの境界の色合いを、プレイヤーのプライマリカラーに合わせて設定します。プレイヤーは、そのオブジェクトの入れ子変数である必要があります。

<ActionParameters />

## 例

```megalo
action boundary_set_player_color current_object owner
```

HREK の `koth.txt` より。
