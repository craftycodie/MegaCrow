# hud_widget_set_text


<AvailabilityCard reach="yes" />

## Description

Updates text on a named HUD widget using a [dynamic string](/language/enums/dynamic-strings).

<ActionParameters />

## Example

```megalo
action hud_widget_set_text must_be_home_widget hud_must_be_home
```

Example from HREK `ctf.txt`.
