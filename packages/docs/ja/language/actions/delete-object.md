# delete_object


<AvailabilityCard reach="yes" />

## 説明

ゲームからオブジェクト参照を削除します。

<ActionParameters />

## 例

```megalo
action delete_object current_object
```

HREK の `ctf.txt` より。

## 注記

- プレイヤーのバイペッドを削除すると、そのプレイヤーは即座にリスポーンします。
