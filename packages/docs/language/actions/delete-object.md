# delete_object


<AvailabilityCard reach="yes" />

## Description

Removes an object reference from the game.

<ActionParameters />

## Example

```megalo
action delete_object current_object
```

Example from HREK `ctf.txt`.

## Notes
* Deleting a player's biped will cause them to instantly respawn.
