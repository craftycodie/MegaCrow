# object_face_object


<AvailabilityCard reach="partial" />

## 説明

オブジェクトを別のオブジェクトの方へ向けて回転させます。

<ActionParameters />

## 例

```megalo
action object_face_object white_orientation black_orientation
```

HREK の `chess.txt` より。

## 注記
- オブジェクトを自分自身の方へ向けると、オフセット値を使ってオブジェクトをヨー軸まわりに回転させることができます。
