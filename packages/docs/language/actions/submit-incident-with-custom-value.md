# submit_incident_with_custom_value


<AvailabilityCard reach="yes" />

## Description

Fires a game incident and passes a custom numeric value. This is used to award achievements to players.

<ActionParameters />

## Example

```megalo
action submit_incident_with_custom_value dlc_achieve_2 player killing_player player killing_player k_cex_achievement_3
```
Example from HREK `ctf.txt`.
