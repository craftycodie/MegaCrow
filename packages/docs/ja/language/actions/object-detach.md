# object_detach


<AvailabilityCard reach="yes" />

## 説明

子オブジェクトを親からデタッチします。

<ActionParameters />

## 例

```megalo
action object_detach current_object
```

HREK の `oddball.txt` より。

## 注記
- 車両に乗っているプレイヤーにこのアクションを適用すると、その車両から降車します。
