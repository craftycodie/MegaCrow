# object_adjust_maximum_shield


<AvailabilityCard reach="yes" />

## 説明

[数学演算](/ja/language/enums/math-operations) を使って、オブジェクトの最大シールドを変更します。100 はシールド 100% です。

<ActionParameters />

## 例

```megalo
action object_adjust_maximum_shield current_object set_to 50
```
