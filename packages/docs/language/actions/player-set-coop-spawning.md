# player_set_coop_spawning


<AvailabilityCard reach="partial" />

## Description

Enables or disables co-op spawning for a player, allowing them to spawn at teammates or objects that have been configured accordingly.

<ActionParameters />

## Example

```megalo
action player_set_coop_spawning current_player 1
```

Example from HREK `race.txt`.
