<AvailabilityCard reach="yes" />

## 説明

プレイヤーがオブジェクトの境界内にいるときに表示される、オブジェクトのプログレスバー表示を設定します。

<ActionParameters />

## 例

```megalo
action set_progress_bar this_territory enemies offense_timer
```
