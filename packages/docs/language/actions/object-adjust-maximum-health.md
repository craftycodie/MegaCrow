# object_adjust_maximum_health


<AvailabilityCard reach="yes" />

## Description

Modifies an object's maximum health with a [math operation](/language/enums/math-operations). 100 is 100% health.

<ActionParameters />

## Example

```megalo
action object_adjust_maximum_health current_player set_to health_give
```

Example from HREK `broken/1.txt`.
