# hud_widget_set_text


<AvailabilityCard reach="yes" />

## 説明

名前付き HUD ウィジェットのテキストを [動的文字列](/ja/language/enums/dynamic-strings) で更新します。

<ActionParameters />

## 例

```megalo
action hud_widget_set_text must_be_home_widget hud_must_be_home
```

HREK の `ctf.txt` より。
