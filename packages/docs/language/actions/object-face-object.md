# object_face_object


<AvailabilityCard reach="partial" />

## Description

Rotates an object to face another object.

<ActionParameters />

## Example

```megalo
action object_face_object white_orientation black_orientation
```

Example from HREK `chess.txt`.

## Notes
- If you have an object face towards itself, you can use the offset values to have an the object rotate on its yaw axis.
