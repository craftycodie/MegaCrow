# get_random_object


<AvailabilityCard reach="partial" />

## 説明

条件に一致するオブジェクトをランダムに選び、出力変数へ書き込みます。`ignore object` パラメータのオブジェクトは選ばれません。

<ActionParameters />

## 例

```megalo
action get_random_object hill_object last_hill the_hill
```

HREK の `koth.txt` より。
