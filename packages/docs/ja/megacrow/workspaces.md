# ワークスペース

**ワークスペース** は、MegaloEvolved を Halo Reach Editing Kit（HREK）の Megalo スクリプトフォルダに向け、Files サイドバーから `.txt` ゲームタイプの参照、開く、コンパイルを行えるようにします。

ワークスペースは **デスクトップ（Tauri）** アプリで利用できます。Files パネルのヘッダーから切り替えを開きます。

## ワークスペース一覧

| 操作 | 内容 |
|------|------|
| **行を選択** | そのワークスペースをアクティブにし、Files ツリーにスクリプトフォルダを読み込みます |
| **Active** バッジ | 現在使用中のワークスペースを示します |
| **Edit** | 名前、スクリプトフォルダ、出力フォルダを変更するワークスペースダイアログを開きます |
| **Delete** | MegaloEvolved からワークスペースを削除します（ディスク上のファイルは削除しません） |
| **Add workspace…** | 新しいワークスペースを作成します |

各行には、そのワークスペースの Megalo バージョン（現在は **107 MCC — Halo Reach**）とスクリプトフォルダのパスも表示されます。

## 追加／編集のフィールド

| フィールド | 必須 | 説明 |
|------------|------|------|
| **Name** | はい | ワークスペース切り替えに表示される名前。スクリプトフォルダを選ぶと、名前が空の場合は HREK の `project.xml` から自動入力されることがあります。 |
| **Megalo version** | 固定 | Reach MCC（`107`）。他のゲーム／バージョンはまだ選択できません。 |
| **Scripts folder** | はい | Megalo ソースのルートフォルダ（通常は `…\data\multiplayer\megalo`）。インクルード、相対パス、Files ツリーはこの場所を基準に解決されます。 |
| **Output folder** | いいえ | **Build** でコンパイルした `.mglo` の出力先。通常は `…\maps\megalo`。省略しても閲覧と編集はできますが、Build には出力パスが必要です。 |

### パスの推測

スクリプトフォルダを参照すると、MegaloEvolved は次を試みます。

1. ワークスペース名用に HREK の `project.xml` 表示名を読む
2. 既に存在する兄弟フォルダ `maps\megalo` を出力フォルダとして検出する

どちらのフィールドもあとから上書きできます。

## ヒント

- スクリプトは単一ファイルではなく、HREK の Megalo データツリーを指定してください。
- ゲーム内ホットリロード向けに `maps/megalo` へワンクリック Build したい場合は、出力フォルダを設定してください。
- 複数のワークスペース（例: 別々の MOD）を保持し、フォルダを選び直さずに切り替えられます。
