# saved_film_insert_marker


<AvailabilityCard reach="yes" />

## Description

Inserts a marker into a saved film recording. The label operand is a [dynamic string](/language/enums/dynamic-strings).

<ActionParameters />

## Example

```megalo
action saved_film_insert_marker -5 "cool marker" 
```
