# player_set_unit


<AvailabilityCard reach="partial" />

## 説明

プレイヤーがバイペッドを操作するように設定します。すでにバイペッドを持っていた場合は、その古いバイペッドを放棄します。

<ActionParameters />

## 例

```megalo
action player_set_unit active_player chess_piece
```

HREK の `chess.txt` より。
