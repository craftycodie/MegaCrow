# set_player_respawn_vehicle


<AvailabilityCard reach="partial" />

## Description

Sets the respawn vehicle type for a player that has been set to spawn in vehicles via [player_set_vehicle-spawning](/language/actions/player-set-vehicle-spawning) (Reach MCC only).

<ActionParameters />

## Example

```megalo
action set_player_respawn_vehicle "warthog" current_player
```
