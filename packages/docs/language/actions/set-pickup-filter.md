# set_pickup_filter


<AvailabilityCard reach="yes" />

## Description

Restricts who can pick up a weapon object (`all`, `allies`, `enemies`, `no_one`). An individual player can also be set to be able to pick up, or not pick up the weapon.

<ActionParameters />

## Example

```megalo
action set_pickup_filter the_bomb allies
```

Example from HREK `assault.txt`.
