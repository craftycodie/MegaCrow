# set


<AvailabilityCard reach="yes" />

## 説明

[算術演算](/ja/language/enums/math-operations)（`set_to`、`add`、`subtract`、`multiply`、`divide`、`modulo`、または `=`）で変数を変更します。対象はカスタム変数、メンバー変数、または組み込みグローバルです。

<ActionParameters />

## 例

```megalo
action set current_player.skulls = 0
```

HREK の `headhunter.txt` より。
